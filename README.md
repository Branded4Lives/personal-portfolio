# Personal Portfolio Website

## Project Description

This project is a personal portfolio website built from a Figma design template.  
The goal was to recreate the layout using HTML and CSS while customizing the content and branding.

The site includes:
- Navigation bar
- Hero section
- Responsive layout
- Client logo section

---

## How to View the Project

### Option 1 – View Live (Recommended)

Visit the deployed site:  
https://branded4lives.github.io/personal-portfolio/

### Option 2 – Run Locally

1. Clone the repository:
   git clone https://github.com/Branded4Lives/personal-portfolio.git

2. Open the project folder.

3. Open `index.html` in a web browser.

No additional setup or dependencies are required.
